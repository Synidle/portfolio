This application was developed in a period of about 2 months for a university mobile application development module, in which I was tasked to make a useful application utilising sensors and APIs. My application received a grade of 82, being a smart concept with solutions to multiple problems.

Problem & Concept

My application solves the problem of technology not yet leveraging its potential to provide a practical advancement upon the phrasebook. Translation apps are impractical when travelling, and specific phrasebook applications prioritise the speed of searching words, rather than offering words as it predicts they are needed.

The purpose of this application is to optimise convenience.

I formed a persona and user journey to identify pain points and opportunities towards my design.

Systems Design

These are the application's features:

  • Automatically suggests phrases based on context
  • Enables saving of phrases
  • Saved phrases can be accessed offline
  • Phrases are categorised by context for quick search
  • Can translate from multiple languages (and scripts)

These are the contexts for which phrases are generated:

  • Location (e.g. airport, bar...)
  • Temperature
  • Time of day

The target language is automatically selected instantaneously based on the device's network.

I decided it best to approximate temperature based on the device battery temperature as this is instant and requires little use of resources; moreover most devices lack ambient temperature sensors.

A recursive algorithm enables phrases to be loaded on a separate thread, and each phrase available as soon as it is loaded, so the user can keep scrolling through phrases seamlessly.

UX Design

The motivation behind my UX Design was ease of use, particularly on a small device, and within any setting. For example, I wanted the application to be navigable with one hand, and without much need to search, or press small buttons.

For comfortability of use, I also decided some features should be accessible by multiple means, fitting the particular intuition of the user.

Given the application should be suitable for as varied contexts as possible, the implementation of a dark theme for low-lit environments was a priority.

Challenges Overcome

Many challenges came from using imperfect, free APIs.

First, the inaccuracy of location data was remedied by asking the user to verify their location.

Second, the translation API would return Chinese and Japanese-language text in their native scripts; while a library existed for romanising Chinese script, none did for Japanese, requiring me to develop my own algorithm that worked in conjunction with a Japanese dictionary API.

Third, the translations themselves can be inaccurate; this is resolved as far as possible heuristically.

A major UX challenge was having the same content on screen whilst it being compact enough for small devices. I ended up omitting the feature of saving phrases directly from the sidebar as it was too difficult to interact with on a phone.

Evaluation & Opportunities

Because of the APIs used, the translations are inaccurate; were this application released commercially, I would make use of an AI language model instead for a greater range of more accurate translations.
